Lesson 1: Introduction to Computer

What is a Computer?

A computer is an electronic device that accepts data, processes it according to instructions, stores it and produces meaningful information.

हिंदी में समझें

कंप्यूटर एक इलेक्ट्रॉनिक उपकरण है जो डेटा प्राप्त करता है, निर्देशों के अनुसार उसे प्रोसेस करता है और उपयोगी जानकारी देता है।

Example:

When you calculate 10 + 20, the computer processes the numbers and displays 30.

Main Characteristics of Computer

  • Speed: Performs tasks quickly.
  • Accuracy: Gives correct results when instructions are correct.
  • Storage: Stores large amounts of data.
  • Diligence: Can repeat tasks without getting tired.
  • Versatility: Performs different types of tasks.

Basic Working of a Computer

Input → Processing → Output

Input: डेटा देना

Processing: डेटा पर काम करना

Output: परिणाम प्राप्त करना

📘 Important Notes

1. Hardware

Physical parts of a computer that we can touch are called hardware.

हिंदी: कंप्यूटर के वे भाग जिन्हें हम छू सकते हैं, हार्डवेयर कहलाते हैं।

Examples: Keyboard, Mouse, Monitor, CPU.

2. Software

A set of programs or instructions that tells a computer what to do is called software.

हिंदी: प्रोग्राम या निर्देशों के समूह को सॉफ्टवेयर कहते हैं।

Examples: Windows, Linux, MS Word.

3. CPU

CPU stands for Central Processing Unit. It performs important processing tasks.

हिंदी: CPU का पूरा नाम सेंट्रल प्रोसेसिंग यूनिट है।

4. Input Devices

Devices used to enter data into a computer are called input devices.

Examples: Keyboard, Mouse, Scanner, Microphone.

5. Output Devices

Devices that display or produce processed results are called output devices.

Examples: Monitor, Printer, Speaker.
